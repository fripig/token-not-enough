關於 Token 撐到月底

你是一位全端工程師，開局選一到兩家公司（Laravel、Rails、Rust、App），在 20 個工作天內用有限的錢和額度，把每天進來的工單交給不同廠商的 AI code agent 處理。免安裝、免註冊，打開瀏覽器就能玩。

  • 選 agent 和模型：Claude Code、Codex CLI、Gemini CLI、DeepSeek、智譜 GLM、Kimi，或用本地 GPU 跑 Qwen、Gemma；向公司申請採購 DGX Spark、Mac Studio，還能跑 GLM-5.3 這類更大的模型。
  • 決定誰付錢：個人訂閱、個人 API、公司 API、公司團隊席位，或自己的電腦。
  • 顧好案主合約（有些案主不能用中國模型）、資安稽核和主管信任。
  • 小心看起來改一行、做下去才發現牽動整個架構的陷阱題。
  • 平行模式同時開 2–6 個 agent，或單線模式一次專心一張單。

怎麼玩

  1. 開局選公司、平行或單線模式，決定這個月要訂閱哪些方案。
  2. 每天點一張工單，在派工台挑廠商、模型、付費方式和審核等級；也可以自己手寫，或先請 agent 評估架構。
  3. 用工時和公司預算做工程投資（CLAUDE.md、單元測試、CI、SDD…），讓之後的派工更省、更穩；也能申請採購電腦，加快本地模型，但買了不用主管會不高興。
  4. 撐到第 20 天月底結算：KPI、主管信任和個人花費決定分數與 S～D 評等。
